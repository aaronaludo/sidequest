# Project

SideQuest

A local-first web app that generates business ideas based on hobbies.

# Stack

- Next.js
- TypeScript
- TailwindCSS
- shadcn/ui

# Architecture

- frontend-only
- local JSON datasets
- no backend
- no database

# Design

Modern startup aesthetic.
Dark mode.
Premium.
Minimal.

# Features

- hobby selector
- business idea cards
- filters
- responsive UI

# Rules

- reusable components
- TypeScript only
- no server logic
- modular code
- mobile-first
